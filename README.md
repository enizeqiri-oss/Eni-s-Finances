# Atelier — Personal Finance App

A calm, editorial finance dashboard for Lena Bühlmann (Kreis 4, Zürich).
Built in the Atelier design language: cream surfaces, Newsreader serif with
italic terracotta accents, JetBrains Mono micro-labels, thin rules,
generous whitespace.

No build step. Plain HTML + one shared CSS file. Open any page in a browser.

## Screens

| File | Screen |
| --- | --- |
| `index.html` | Overview — net worth, portfolio, cash flow, bills, spending, activity |
| `income.html` | Income setup — multi-step form with live Brutto → Netto card |
| `bills.html` | Monthly commitments — 8 fixed bills, status pills, filters |
| `upload.html` | Document inbox — OCR drop zone, parsing demo, confidence bars |
| `summary.html` | May in review — saved/in/out/rate, 6-month bar chart, insights |
| `summary-print.html` | Print-ready A4 of the monthly statement |
| `mobile.html` | iOS companion (390 × 844) — net worth, up-next, top buckets, FAB |
